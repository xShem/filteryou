# YouTube Free Filter

Самостоятельное расширение Chrome / Chromium (Manifest V3). Написано заново по общим идеям фильтрации видео; код исходного расширения не используется. Все возможности бесплатны: нет аккаунтов, подписок, ключей API, аналитики и запросов к сторонним серверам. Настройки хранятся в `chrome.storage.local` на этом устройстве.

## Установка

1. Откройте `chrome://extensions` в браузере, где разрешены расширения разработчика.
2. Включите «Режим разработчика» → «Загрузить распакованное расширение».
3. Выберите **эту папку** `youtube-free-filter`, а не корень репозитория.
4. Обновите уже открытые вкладки YouTube. Закрепите значок расширения для удобства.
5. Откройте значок, задайте фильтры и нажмите «Применить».

Изменения настроек действуют на открытые вкладки и новые карточки без перезагрузки. Выключение фильтров или сброс возвращает скрытые карточки. После изменения кода перезагрузите расширение на странице расширений и вкладки YouTube.

## Возможности

- Минимум и максимум просмотров и длительности.
- Максимальный возраст публикации в днях.
- Скрытие Shorts и текущих прямых эфиров.
- Включение и исключение слов в названии, исключение каналов по части имени (без учёта регистра, разделитель — запятая).
- Сохранение настроек и обработка динамически загружаемых карточек.
- Выбор поведения, когда числовые данные неизвестны.

Фильтруются загруженные карточки на главной, в поиске, на каналах и в рекомендациях рядом с видео. Плейлисты и текущий видеоплеер не фильтруются. Это фильтрация отображения: расширение не меняет поисковый алгоритм и не загружает дополнительные результаты взамен скрытых.

## Ограничения

Числовые метаданные распознаются для русских и английских подписей. YouTube округляет просмотры и даты; месяц считается как 30 дней, год — 365. Для других языков и карточек без метаданных действует выбранная политика неизвестных данных. Фильтр каналов ищет текстовое совпадение, а не идентификатор канала. Изменения разметки YouTube могут потребовать обновить селекторы в `content.js`. Лента вертикального Shorts-плеера не поддерживается.

## Разработка и проверка

Зависимостей и сборки нет. Из этой папки:

```sh
node --test tests/*.test.cjs
for f in *.js; do node --check "$f" || exit; done
```

Тесты проверяют парсинг, правила, комплектность манифеста и обработку новых карточек/настроек на модели DOM. Это не заменяет проверку на настоящем YouTube.

В ограниченной облачной песочнице запуск дочернего тестового процесса может быть недоступен. На установленном Node.js 24 проверено выполнение без изоляции процессов: `node --test --test-isolation=none tests/*.test.cjs` (6 тестов успешно).

Ручная проверка: задайте заведомо высокий минимум просмотров, убедитесь, что карточки скрываются, затем отключите фильтры — карточки должны вернуться. Проверьте поиск, главную, рекомендации, прокрутку и переход между страницами без перезагрузки. Настройки должны сохраняться после закрытия окна расширения.

В облачной среде этой задачи Chromium запрещает распакованные расширения административной политикой. Проверка на настоящем YouTube здесь не выполнена; используйте браузер с разрешённой установкой. Политику обходить не требуется.
