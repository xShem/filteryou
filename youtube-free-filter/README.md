# YouTube Free Filter Studio 2

Самостоятельная бесплатная альтернатива для Chrome / Chromium (Manifest V3), написанная заново по идеям фильтрации из исходного расширения. Этот проект находится **отдельно в `youtube-free-filter/`**. Исходные собранные файлы в корне репозитория не используются и не изменяются.

Нет пейвола, подписок, аккаунтов, платных API, телеметрии или серверной регистрации. Для установки не нужны Node.js, npm и сборка.

## Установка и обновление

1. Скачайте репозиторий: [ZIP ветки main](https://github.com/xShem/filteryou/archive/refs/heads/main.zip).
2. Распакуйте его. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите **папку `youtube-free-filter`, где находится этот README и `manifest.json`**, а не корень архива.
4. Обновите уже открытые вкладки YouTube.
5. Откройте значок расширения или кнопку **◈ Free Filter** в правом нижнем углу YouTube. Панель также открывается сочетанием **Alt+Shift+F**. Escape закрывает панель.

Для обновления замените файлы ранее установленной папки, нажмите «Обновить» на карточке расширения в `chrome://extensions` и обновите вкладки YouTube. Настройки версии 1 сохраняются; новые поля получают значения по умолчанию. Блокировки и коллекция хранятся локально.

Браузер должен разрешать установку распакованных расширений. Административные запреты расширение не обходит.

## Возможности

### Фильтры видео

- Минимальные/максимальные просмотры и длительность; минуты или точные секунды (секунды имеют приоритет для своей границы).
- Возраст публикации, даты «с / по» включительно, средние просмотры в день.
- Тип: все видео, без Shorts, только Shorts или текущие эфиры.
- Скрытие просмотренных карточек, эфиров, запланированных премьер, плейлистов и миксов.
- Лайки, комментарии, их отношение к просмотрам в процентах, отношение просмотров к подписчикам канала.
- Наличие корректных глав в описании, наличие субтитров и языки субтитров.
- Любое / все включённые слова / точная фраза в названии, исключённые слова, слова в описании. Строгий поиск требует все слова текущего поискового запроса в названии.

### Фильтры каналов

- Включение и исключение по части имени; подтверждённость канала.
- Подписчики, количество видео, суммарные просмотры, дата создания канала.
- Включение/исключение стран и слов в описании канала.
- Публичный email в описании; ссылки на Telegram, Instagram, Discord, Twitter/X, TikTok, Facebook, Twitch, Patreon, LinkedIn, GitHub или сайт.
- Блокировка конкретного канала или видео по ID, а не по изменяемому названию. Список блокировок с разблокировкой доступен в разделе «Каналы».

### Рабочий процесс

- Панель на странице YouTube и окно по значку расширения.
- Под карточками: подробности, сохранение в коллекцию, блокировка видео/канала, средние просмотры в день.
- Подробности: публичная статистика видео и канала, описание, теги, список языков субтитров с пометкой автоматических, главы с переходом по времени, публичные контакты. Предпросмотр во встроенном YouTube-плеере запускается отдельной кнопкой; автор может запретить встраивание.
- 6 встроенных пресетов, до 30 пользовательских пресетов, коллекция до 1000 видео.
- Сортировка загруженных карточек: просмотры, новизна, длительность, средние просмотры/день, лайки, подписчики, отношение просмотров к подписчикам, название.
- Аналитика текущей выдачи: количество загруженных/скрытых видео, сумма и медиана просмотров, календарь публикаций, список видео с причинами скрытия.
- Экспорт выдачи в CSV и отчёта в JSON. Резервная копия настроек, пресетов, блокировок и коллекции; проверяемый импорт JSON.
- Поиск YouTube с операторами `after:` и `before:` по выбранным датам. Для поиска по каналу добавьте его имя в запрос; это не выгрузка всего канала.
- Пауза немедленно возвращает скрытые карточки. «Показать скрытые» временно отображает их приглушёнными с причинами фильтрации.

## Откуда берутся данные

По умолчанию используются только уже загруженные карточки YouTube; **автоматическая подгрузка выключена**. Для точных дат, описаний, глав, субтитров, лайков и статистики канала включите «Настройки → Подгружать публичные данные» и нажмите «Применить».

Расширение получает публичные страницы `www.youtube.com/watch` и `/channel/.../about` без cookies, API-ключей и выполнения кода страницы. До 30 видео на страницу, максимум 2 сетевых запроса одновременно. «Аналитика → Ещё до 30 видео» разрешает следующую порцию. Запросы повторяющихся ID объединяются; успешные ответы кэшируются на 24 часа. Кэш периодически очищается (около 400 записей); его можно очистить вручную. Ошибки не превращаются в выдуманные нулевые значения. «Подробности» делает запрос по явному нажатию, даже если автоподгрузка выключена.

Обычные карточки парсятся для русских и английских подписей. YouTube может округлять просмотры, подписчиков, даты и реакции. Даты из карточек приблизительны: месяц = 30 дней, год = 365. Даты из публичной страницы точнее, но не всегда содержат время. Страны обычно приходят по-английски — используйте полное имя, например `United States`, а не `US`.

Настройка «Если данных для активного фильтра нет» действует на отсутствующие данные. Пустой список субтитров после успешной загрузки означает, что субтитры не найдены; отсутствие загруженных данных — другое состояние. При политике «оставлять» расширенный фильтр не скрывает карточку, пока нужные данные неизвестны.

## Честное сравнение с исходником

| Функция исходного расширения | Реализация в Studio |
| --- | --- |
| Фильтры просмотров, длительности, дат, текста и каналов | Да, локально |
| Подписчики, статистика/страна/дата канала, лайки и комментарии | Из публичных страниц, если YouTube раскрывает данные |
| Главы, описания, языки субтитров, теги, публичные контакты | Да, из публичных данных; текст субтитров не выгружается |
| Быстрый просмотр, подробности | Своя панель, предпросмотр и главы |
| Пресеты, блокировки, статистика выдачи, экспорт | Да, без оплаты |
| Поиск по датам канала | Общий поиск с датами и именем канала; полного индекса канала нет |
| Performance / velocity | Прозрачные расчёты: просмотры/день и просмотры/подписчики; не копия серверного рейтинга |
| История роста, тренды, анализ всех загрузок канала | Нет: календарь и расчёты относятся только к загруженной выборке |
| Дизлайки и их доли | Нет: YouTube не публикует их; сторонняя оценка не подменяется нулём |
| AI-чат, AI-резюме, AI-детектор | Нет: модель и сервер исходного продукта не воспроизводятся |
| Серверные аккаунты, квоты, оплаты | Отсутствуют |

Это расширенная самостоятельная альтернатива, а не полный функциональный клон серверных возможностей исходного продукта. Платные ограничения исходника не снимаются; его код не импортируется.

## Ограничения

Фильтруется отображение **уже загруженных** карточек. Расширение не меняет алгоритм рекомендаций, не скачивает всю выдачу и не гарантирует автоматическую загрузку следующей страницы, если всё скрыто. Плеер текущего видео, вертикальная Shorts-лента и сами элементы плейлистов не фильтруются.

Сортировка работает CSS-порядком в совместимых flex/grid-списках YouTube, не перемещая управляемые YouTube DOM-узлы. Между разными секциями/полками глобальная перестановка не гарантируется; для единой сортировки выборки используйте список «Аналитика». YouTube меняет разметку — селекторы в `dom.js` и публичный парсер могут потребовать обновления. Обнаружение просмотренного основано на доступной полоске прогресса карточки, не на чтении истории аккаунта.

Consent-страницы, возрастные/региональные ограничения, блокировки, ограничение запросов и отсутствие публичных полей могут мешать подгрузке. Расширение не обходит ограничения, не входит в аккаунт и не гарантирует данные каждого видео/канала. Описания и внешние названия отображаются как текст, не как HTML.

## Проверка и разработка

Обычная работа не требует зависимостей. Для тестов нужен Node.js 20+:

```sh
cd youtube-free-filter
node --test tests/*.test.cjs
for f in *.js; do node --check "$f" || exit; done
```

В ограниченной облачной песочнице на Node.js 24 проверено:

```sh
node --test --test-isolation=none tests/*.test.cjs
```

Браузерные проверки запускаются отдельно при наличии Playwright и Chromium:

```sh
node tests/browser-smoke.cjs
# Необязательно: CHROMIUM_PATH=/путь/к/chromium node tests/browser-smoke.cjs
```

Для проверок в этой среде использован предустановленный Playwright 1.62.1 и Chromium 154. Браузерный тест подставляет локальные модели страниц и Chrome API, не устанавливает расширение и не обращается к живому YouTube. Он проверяет настоящий DOM и интерфейс, но не подтверждает совместимость парсера с текущими ответами YouTube или работу Chrome API установленного расширения.

Проверено: 22 модульных/интеграционных теста (правила, парсинг JSON, обработка ошибок, кэш, очередь, безопасность CSV) и 2 браузерных сценария (динамические карточки, повторное использование узлов, сортировка, блокировки, лимит подгрузки; настройки, пресеты, аналитика, импорт/экспорт). Проверка установленного расширения на живом YouTube в облачной среде не выполнена: политика Chromium запрещает распакованные расширения.

После установки в разрешённом браузере проверьте главную, поиск, канал и рекомендации: высокий минимум просмотров скрывает карточки; пауза возвращает их; прокрутка применяет фильтры к новым карточкам; «Подробности» показывает данные либо понятную ошибку; настройки и коллекция сохраняются после перезапуска браузера.
