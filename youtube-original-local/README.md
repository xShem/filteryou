# Original Local Edition

**Адаптация исходных скриптов из корня этого репозитория**, а не расширение Free Filter Studio из соседней папки. Здесь сохранены исходные интерфейс, фильтрующий движок, модальные результаты, сортировка, пресеты, подробности и интеграция с YouTube. Версия сборки: `2.0.185.1`.

## Установка

1. Распакуйте архив этой папки или скачайте репозиторий с GitHub.
2. В Chrome / Chromium откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите **`youtube-original-local`**, где находится этот `manifest.json`.
4. Обновите открытые вкладки YouTube. Возле поиска появится кнопка **«Фильтры» / Filters**. Панель можно открыть через **Alt+Shift+F**.

При обновлении замените файлы той же установленной папки, нажмите кнопку обновления расширения и обновите вкладку YouTube. Для чистой проверки отключите одновременно работающие версии других YouTube-фильтров: они могут менять одни и те же карточки.

Для установки не требуются npm, сборка, регистрация или лицензия. У расширения собственный ID: ключ официального расширения и его URL автообновления удалены. Оно не выдаёт себя за официальный продукт. Исходные уведомления об авторстве в скриптах сохранены.

## Что изменено

- Файлы собраны в структуру расширения: `assets/`, `icons/`, `_locales/`, манифест и worker. В исходном репозитории ресурсы лежали в корне, а манифест ссылался на отсутствующие папки.
- Устранён неоднозначный запуск: вместо запуска основного bundle при импорте используется одна функция `onExecute`, ожидаемая загрузчиком. Повторный вызов не создаёт вторую панель.
- Исправлены два обращения к отсутствующему `getQuotaState` в исходной точке входа.
- Модуль MAIN world загружается через `chrome.scripting` с абсолютным URL расширения. Ошибка инъекции возвращается вызывающему коду, а не маскируется успешным ответом. Этот модуль нужен для чтения доступных данных YouTube и работы исходных функций.
- **Локальные ограничения** поиска, экспорта, AI-интерфейса, быстрого просмотра, статистики и сортировки заменены режимом без счётчиков. Сохранённая исчерпанная квота не блокирует операции. Локальный режим не требует входа и не сообщает серверу о якобы оплаченной подписке.
- Убраны из доступного интерфейса профиль/покупки, запросы лицензий и подарочных кодов, платёжные окна и предложения пожертвований. Учитывается Shadow DOM исходной панели.
- Фоновый код Supabase/auth/billing заменён маленьким локальным worker. Вход через Google в сервис разработчика и создание/активация лицензий не выполняются. Локальные ответы имеют `isPaying: false`, `isLifetime: false` и `localEdition: true`.
- Приватный enrichment-сервис разработчика отключён. Сохранены **существующие в исходных скриптах** способы получения публичных данных непосредственно с YouTube. Серверные проверки доступа, квоты YouTube и недоступные функции аккаунта не обходятся.
- Аналитика использования отключена; отправка аналитических событий и генерация tracking-ID отключены в адаптированном общем модуле. Настройки перенесены из `chrome.storage.sync` в `chrome.storage.local`.
- Из имеющихся строк восстановлены/сгенерированы 793 сообщения. Есть русские названия основных элементов; остальные строки используют английские тексты или читаемые подписи. Это **не восстановление утраченного оригинального перевода**.
- Отсутствующие иконки заменены новыми простыми иконками. Отсутствующие обучающие `.mp4` не имитируются: их предзагрузка удалена, вместо видеоподсказок оставлен текст.

Скрипты в корне и папка `youtube-free-filter` не меняются. `build-report.json` содержит SHA-256 всех исходных файлов корня и перечень изменённых функций. Код исходных фильтров и парсеров не заменён упрощённым движком Studio.

## Что зависит от YouTube и внешних данных

Отсутствие локального пейвола **не гарантирует доступность каждой функции исходника**:

- YouTube может менять DOM, ответы API и правила доступа, скрывать лайки, комментарии, подписчиков или запрещать встраивание.
- AI-интерфейс исходника использует функции самого YouTube. Сохранён его код; доступность зависит от YouTube, аккаунта и конкретного видео. Собственная AI-модель или платный сервер не добавляются.
- Дизлайки, если доступны, по-прежнему получает исходный код из публичного `returnyoutubedislikeapi.com`. Это сторонняя оценка, а не скрытая официальная статистика YouTube. Сервис может быть недоступен или ограничивать частоту.
- Закрытый enrichment-сервер, лицензии, аккаунты и инфраструктура разработчика в эту папку не включены. Они отключены; исходные публичные способы загрузки данных сохранены. Если их тоже ограничивает YouTube, поле останется недоступным.
- Разрешение `scripting` нужно для загрузки оригинального модуля в MAIN world YouTube. Разрешения на сайты ограничены YouTube и публичным API дизлайков. Доступ к сервисам оплаты и Supabase удалён из манифеста.

В этой задаче не выполнялись запросы к закрытым сервисам и не проверялась работа функций на живом YouTube. Не утверждается, что все серверные возможности исходника восстановлены.

## Проверка

Проверено в этой среде:

- 10 автоматических проверок: комплектность манифеста и модулей, SHA-256 оригиналов, отсутствие private/billing-разрешений, локальные операции при исчерпанной квоте, повторные операции без уменьшения лимита, запуск MAIN world и обработка отказа, отсутствие фиктивной активации лицензии.
- Chromium: запуск исходного основного и MAIN-world bundle, открытие единственной исходной панели с 56 полями, вкладки видео/каналов, сохранение фильтров, исходные правила просмотров/длительности, скрытие профиля и отсутствие запросов к отсутствующим файлам или приватному backend на тестовой странице.

Браузерная проверка использует локальную модель страницы и mock Chrome API. Установка распакованного расширения в облачный Chromium запрещена его административной политикой. Поэтому **реальная установка, Chrome API и живые ответы YouTube пока не проверены**. Финальную проверку нужно выполнить в браузере, разрешающем установку расширения.

## Воспроизведение изменений и тестов

Готовые файлы уже находятся в этой папке. Сборщик нужен только разработчику, если требуется повторить изменения из оригиналов в корне. Для него нужен Acorn 8.15.0; для браузерной проверки — Playwright и Chromium. В этой среде использовались Node.js 24, Acorn 8.15.0, Playwright 1.62.1 и Chromium 154.

```sh
# Из корня репозитория. Сторонние инструменты — вне checkout:
npm install --prefix /tmp/yfp-build --no-save --ignore-scripts acorn@8.15.0
YFP_ACORN_MODULE=/tmp/yfp-build/node_modules/acorn node youtube-original-local/tools/rebuild.cjs
YFP_ACORN_MODULE=/tmp/yfp-build/node_modules/acorn node --test --test-isolation=none youtube-original-local/tests/unit.test.cjs

# Если Playwright доступен для require('playwright'):
node youtube-original-local/tests/browser.cjs
```

Сборщик применяет изменения только к копиям и останавливается, если ожидаемая структура исходных скриптов изменилась. CSS локального режима, worker, иконки и тесты также входят в Git. Корневые bundle не перезаписываются.
